## Routing Principles
- Use quick review when a fast issue screen is enough.
- Use standard review for most court-facing drafts.
- Use deep review only when the extra cost is justified.
- Use workflow triage when the user is trying to understand a new event, decide whether to escalate, or decide whether to preserve something for pattern use.
- Use counsel brief when the user needs a concise Kaitlyn or Jessika-ready email, agenda, or update.
- Use Special Master triage when the real question is whether the issue is ripe, narrow, and administrable enough for that forum.
- Use draft-message when the user needs copy-paste-ready OFW, Special Master, provider, school, or counsel language.
- Use authority check when the real question is what authority is supplied, missing, or still needs attorney confirmation.
- Use strategy review when a current draft needs leverage, status-quo analysis, or procedural creativity.
- Trigger child, financial, and legal-authority agents only when their issue domains are actually in play.
