# Source Hierarchy

Use this hierarchy whenever source strength matters.

## Tier 1
Court orders and official records.

## Tier 2
Contemporary third-party records, including school, medical, therapy, provider, and authenticated communication records.

## Tier 3
Attorney communications, attorney drafts, strategy memos, and attorney work product supplied for review.

## Tier 4
User notes, recollections, journals, and informal summaries.

## Tier 5
AI-generated summaries and workflow outputs.

Rules:
- AI-generated summaries are never evidence.
- Source tier affects safe-use guidance.
- Party allegations should not be upgraded to established facts.
- Legal authority should be treated separately from factual support.
- When producing a final packet, label important statements using the source-strength taxonomy:
  - Locked / source-supported fact
  - User recollection / user assertion
  - Inference
  - Disputed allegation
  - Unsupported claim
  - Legal proposition needing authority
  - Attorney-only / internal strategy
  - External-safe fact
- A source weakness is not automatically fatal. Explain what it means, what risk it creates, and what source would fix it.
